# AI-Assisted Software Engineering

## 1. Effective Prompting

AI was used with specific prompts describing the project requirements, existing
code structure, required features, and expected output.

Examples of prompts used:

- "Create an Employee Management System using Python and OOP."
- "Add CRUD operations for employees."
- "Implement Divide-and-Conquer Merge Sort for employee salary sorting."
- "Create pytest tests for the employee management functions."
- "Create a FastAPI backend for the Employee Management System."
- "Create a GitHub Actions CI workflow to run pytest."
- "Follow the Project Defence flow step-by-step."

Specific prompts helped generate code relevant to the project instead of
generic code.

## 2. Context Management

Relevant project context was provided to the AI before requesting changes.

The context included:

- Existing Python files
- Employee data structure
- Existing functions and classes
- Testing requirements
- Project Defence flowchart
- Frontend and backend structure

The AI was instructed to modify the existing project instead of replacing the
entire project unnecessarily.

## 3. Specification-First Development

The Project Defence requirements were considered before implementation.

The development workflow followed:

Real-World Problem
        ↓
Computational Thinking
        ↓
Problem Decomposition & Abstraction
        ↓
Algorithm & Data-Structure Selection
        ↓
Python Implementation
        ↓
OOP / Functional Design
        ↓
Concurrency Evaluation
        ↓
Testing & Quality Engineering
        ↓
CI/CD
        ↓
AI-Assisted Development & Code Review

This helped ensure that implementation decisions were connected to project
requirements.

## 4. AI-Assisted Code Generation

AI was used to assist with:

- Python class and function implementation
- Employee CRUD operations
- Divide-and-Conquer Merge Sort
- pytest test cases
- FastAPI backend
- React frontend integration
- GitHub Actions CI configuration

AI-generated code was integrated into the existing project and adapted to the
project requirements.

## 5. Critical Review and Validation

AI-generated code was not accepted without testing.

The code was reviewed and validated by:

- Running the Employee Management System
- Testing CRUD operations
- Running pytest
- Testing the Merge Sort algorithm
- Checking API connectivity
- Testing the React frontend
- Running GitHub Actions CI

The employee tests successfully passed.

The Merge Sort test successfully passed.

GitHub Actions CI also completed successfully.

Therefore, AI was used as an assistance tool, while the final implementation
was reviewed and validated by the developer.
